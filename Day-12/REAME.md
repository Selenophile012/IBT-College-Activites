# Habesha Eatery Mini-Site

Habesha Eatery is a fictional Ethiopian restaurant website created for CodeOps Module 2 Day 12.

## Pages

- `index.html` - Reservation page with reservation form, menu table, image, and map.
- `contact.html` - Contact form and opening-hours table.

## How to Open

Open `index.html` in a web browser.

Use the navigation links to move between the Reservations and Contact pages.

## Accessibility Features

- Semantic HTML elements are used.
- Each page has exactly one h1.
- All form controls have labels.
- Form inputs use appropriate input types.
- Phone number validation is included.
- Tables have captions.
- Table headers use scope attributes.
- Images have meaningful alt text.
- The map iframe has a descriptive title.
- Navigation links work with the keyboard.
- Native HTML buttons are used instead of div elements as buttons.
- Each page has a unique title and meta description.
