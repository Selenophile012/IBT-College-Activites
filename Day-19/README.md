# Addis Market Shopping List

An interactive shopping list built with HTML, CSS and JavaScript.

## What It Does

The application allows users to:

- Add a shopping item
- Enter the item's price in ETB
- Mark an item as bought
- Delete an item
- See the live total of all item prices

## Files

### index.html

Contains the structure of the application, including the form, shopping list and total.

### styles.css

Contains the styling of the application, including the bought state.

### app.js

Contains the JavaScript functionality for adding, deleting and marking items as bought.

It uses DOM selection, createElement, append, event listeners, event delegation, preventDefault, classList and reduce.

## How to Open

Open `index.html` in a web browser.

No additional installation is required.
